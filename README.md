## 🚀 Projeto em destaque: Task Manager

Aplicação full stack construída do zero para consolidar arquitetura limpa e boas práticas de engenharia — do domínio ao deploy.

- **[TaskManager API](https://github.com/sergiobsilva2505/task-manager)** — Backend em **Java 21 + Spring Boot 4**, seguindo **Arquitetura Hexagonal** rigorosa (domínio isolado de framework). Autenticação **JWT** própria + **login social via Google (OAuth2)**, multiusuário com isolamento de dados por dono, e endpoint de dashboard com métricas agregadas. Cobertura de testes em pirâmide completa (**unitário, integração com Testcontainers, arquitetura com ArchUnit**), migrações versionadas com **Liquibase**, documentação **OpenAPI/Swagger**, e **CI** com GitHub Actions.
- **[TaskManager Web](https://github.com/sergiobsilva2505/taskmanager-web)** — Frontend em **Angular 22**, espelhando a mesma disciplina de Arquitetura Hexagonal do backend, consumindo a TaskManager API de ponta a ponta (autenticação, CRUD de tarefas, dashboard).
